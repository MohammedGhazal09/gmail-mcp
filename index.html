Gmail MCP

A private, single-user tool for reading and sending Gmail from a local AI assistant.

Gmail MCP is a personal integration that connects a locally running AI assistant to one Gmail mailbox. It is not a public service, has no sign-up, and is used by exactly one person: the mailbox owner.

What it does

  • Lists and reads messages and threads in the owner's own mailbox.
  • Sends mail and manages labels, drafts, and read state, only when the owner explicitly asks.

How it runs

The integration runs entirely on the owner's computer. It talks to the Gmail API over HTTPS using OAuth 2.0, and the resulting access token is stored locally on that machine. There is no server, no database, and no third-party backend.

Permissions

It requests the Gmail scope needed to read and manage the owner's own mail. It cannot access anyone else's account and does not request access to any other Google service.
