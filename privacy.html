Privacy Policy

Gmail MCP · last updated 29 October 2026

Gmail MCP is a private, single-user integration that connects a locally running AI assistant to one Gmail mailbox owned by the operator of this tool. This policy describes exactly what happens to data.

What is collected

The tool reads Gmail messages, threads, labels, and profile information belonging to the single authorizing account, and only for the duration of a request made by that account's owner.

Where data goes

  • Message content is passed to the AI assistant running on the owner's own computer.
  • Nothing is sent to this website, to GitHub Pages, or to any server operated by the author.
  • Nothing is sold, rented, or shared with advertisers or data brokers.

Storage

OAuth credentials (an access token and a refresh token) are stored in a local configuration file on the owner's computer. Message bodies are not stored in any database and are not retained after a request completes, except where the owner chooses to save a draft or send a message through Gmail itself.

Third parties

The only third party involved is Google, through the Gmail API, governed by Google's Privacy Policy. This site is hosted on GitHub Pages, which may log standard web request data such as IP addresses; see GitHub's privacy statement.

Revoking access

The owner can revoke this application's access at any time from Google Account permissions, and can delete the local credentials file to remove all stored tokens.

Children

This tool is not directed at children and has no public users.

Changes

Any change to this policy will be published on this page.
